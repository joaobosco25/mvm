## Tecnologia

O projeto usa **HTML5 + CSS3 + JavaScript + React 18**. O **GSAP** é usado somente na abertura minimalista. A rolagem é totalmente nativa do navegador; não há Lenis, ScrollTrigger ou qualquer rotina que intercepte roda do mouse ou gestos de toque.

## Abertura

A abertura não utiliza a imagem da logo. Ela usa um símbolo jurídico dourado gerado especificamente para o projeto, sobre fundo azul-marinho escuro, com animação curta de entrada e saída.

## Execução

Abra a pasta no VS Code e execute `index.html` usando Live Server. Como React, ReactDOM, GSAP e as fontes são carregados por CDN, o navegador precisa de conexão com a internet para carregar essas bibliotecas.
